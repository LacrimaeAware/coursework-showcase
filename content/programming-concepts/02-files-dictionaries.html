Golf scores in a text file

Chapter 6, Assignment 10 collects a player name and integer score, stores each pair on its own line, then reads the file back. The while True loop keeps asking for records until a name begins with exit. An invalid score triggers ValueError, the conversion error caught by the program, and the prompts begin again.

with open closes the file when its block finishes. Mode "w" replaces the file with this session’s records; mode "r" reads those records. The relative path ../golf.txt places the file one folder above the script’s working directory.

A run containing an invalid score followed by two valid records ends with:

Player Scores:

Player A, 71
Player B, 68

# Record and display user name records.

def record_scores():
    # Ask player names and golf scores
    print(
        "Please, input each player's name and their respective score."
        "\nWhen done type exit.\n"
    )

    player_records = ""
    while True:
        try:
            player_name = input("Player name: ").strip()
            if player_name.lower().startswith("exit"):
                print("...\nThank you for playing at Springfork Amateur Golf Club!\n")
                break
            player_score = int(input("Player score: "))
            player_records += player_name + ", " + str(player_score) + "\n"
        except ValueError:
            print("Please enter integer values only. Try again.")
            continue

    with open("../golf.txt", "w") as scores_file:
        scores_file.write(player_records)

def display_scores():
    # Display contents of golf.txt
    print("Player Scores:\n")
    with open("../golf.txt", "r") as scores_file:
        player_records = scores_file.read()

    for player in player_records.strip().split("\n"):
        print(player)

record_scores()
display_scores()

Course information in dictionaries

Chapter 9, Assignment 1 uses a course number as the key in three dictionaries: room, teacher and meeting time. A dictionary stores key–value pairs so the same course key can retrieve each kind of information. upper() normalizes the typed course number, and course in rooms checks for an existing key before looking it up.

Entering cs101 returns the exercise’s sample record:

room: 3004
teacher: Haynes
time: 8:00 am

An unknown course such as CS999 prints Incorrect course number.

Read the complete Python program: course-lookup.py

# Course Info Lookup

# get course from user
def get_course():
    return input("Enter course number: ").upper()

# print info for course
def course_info(course):
    rooms = {'CS101': 3004, 'CS102': 4501, 'CS103': 6755, 'NT110': 1244, 'CM241': 1411}
    profs = {'CS101': 'Haynes', 'CS102': 'Alvarado', 'CS103': 'Rich', 'NT110': 'Burke', 'CM241': 'Lee'}
    times = {'CS101': '8:00 am', 'CS102': '9:00 am', 'CS103': '10:00 am', 'NT110': '11:00 am', 'CM241': '1:00 pm'}

    if course in rooms:
        print(f"room: {rooms[course]}")
        print(f"teacher: {profs[course]}")
        print(f"time: {times[course]}")
    else:
        print("Incorrect course number.")

# main thing
def main():
    course = get_course()
    course_info(course)

if __name__ == "__main__":
    main()
