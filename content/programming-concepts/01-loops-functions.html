Distance at each hour

Chapter 4, Assignment 4 takes a constant vehicle speed and a number of whole hours, then prints the distance reached at each hour. The for loop repeats the multiplication for each value from range(1, vehicle_time + 1). Adding one to the upper bound includes the final hour because Python stops before that bound.

With speed 60 and time 3, the program prints:

Hour      Distance Travelled
1         60
2         120
3         180
Read the complete Python program: distance-table.py
# Calculate distance traveled by vehicle

# Get vehicle variables
vehicle_speed = int(input("What is the speed of the vehicle? "))
vehicle_time = int(input("How many hours has the vehicle travelled? "))

# Display distance travelled by hour
print("Hour", " "*4, "Distance Travelled")
for i in range(1, vehicle_time+1):
    print(i, " "*(8-len(str(i))), vehicle_speed*i)

Monthly and annual automobile costs

Chapter 5, Assignment 4 separates a calculation from the prompts. calcExpenses receives six monthly costs and returns their sum. main reads the inputs, calls that function, then multiplies the monthly total by twelve for the annual total. float converts each typed value to a number that can include a decimal part.

Monthly inputs 100, 50, 80, 10, 15, 25 produce:

Total monthly expense: $ 280.0
Total annual expense: $ 3360.0
Read the complete Python program: automobile-expenses.py
# Calculate monthly and annual automobile expenses

def calcExpenses(loan, insurance, gas, oil, tires, maintenance):
    # Returns total monthly expenses
    return loan + insurance + gas + oil + tires + maintenance

def main():
    print("Please enter your individual MONTHLY expenses.")

    loan = float(input("Loan payment: "))
    insurance = float(input("Insurance payment: "))
    gas = float(input("Gas cost: "))
    oil = float(input("Oil cost: "))
    tires = float(input("Tire cost: "))
    maintenance = float(input("Maintenance cost: "))

    total_monthly = calcExpenses(loan, insurance, gas, oil, tires, maintenance)
    total_annual = total_monthly * 12

    print("\nTotal monthly expense: $", round(total_monthly, 2))
    print("Total annual expense: $", round(total_annual, 2))

main()
