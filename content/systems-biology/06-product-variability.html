Variation across starting counts

The variability grid holds volume fixed and varies the starting enzyme and substrate counts. Each grid cell summarizes product values from repeated simulations at the same observation time.

Coefficient of variation

Across the repeated runs, \(\overline P\) is the mean product count and \(s_P\) is its sample standard deviation. The coefficient of variation (CV) expresses the spread as a fraction of the mean.

\[\mathrm{CV}=\frac{s_P}{\overline P}\]

The low-enzyme cells have the greatest relative variation in this grid. Each run contributes its latest recorded product count at \(t=100\); the count stays constant between reaction events.

Fixed-time observation

Runs have different reaction times. Reading the state held at the same clock time gives one comparable product count from each run.

The sample variance uses denominator \(n-1\). CV is defined for a positive sample mean; a zero mean gives an undefined value.

Fixed-time counts and event windows

The time-window example selects recorded product values inside a narrow interval. Orange points are event records with \(98<t<102\). Black diamonds mark each displayed run's product count held at \(t=100\).

The histogram uses one fixed-time count from every run. The selected event records retain their run identities.

Time-window example settings

Initial enzyme \(E_0=10\), substrate \(S_0=300\), target time \(100\), half-width \(f=2\), and seed \(1109\). The example selects times strictly between \(100-f\) and \(100+f\). Reaction constants match the heatmap's second rate set.
