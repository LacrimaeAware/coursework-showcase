Methods for rounded calculations

The Chapter 6 stock-calculation program separates repeated arithmetic into two methods. calcStockCost multiplies a share count by a price and rounds the result to cents. sharesStock divides sale proceeds by another price and rounds the quotient to one decimal place.

double total_paid = calcStockCost(num_shares, a_price);
double total_sell = calcStockCost(num_shares, a_sell);
double total_gained = total_sell - total_paid;
double shares_to_buy = sharesStock(total_sell, b_price);

For \(100\) shares bought at \(10\) dollars and sold at \(12\) dollars, the program reports \(200\) dollars gained. Sale proceeds of \(1200\) dollars buy \(60.0\) shares at \(20\) dollars each. A second input, \(10\) shares bought at \(12\) dollars and sold at \(8\), follows the loss branch and reports \(40\) dollars lost.

The program parses numeric input directly; these examples use valid numbers and a positive second-stock price. Its two methods make the calculation reusable while the loop controls whether to process another input set.

/*
 * Programming Assignment 5
 * Calculating Stocks Program
 */

import java.util.Scanner;

class StockCalculation {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String again = "y";

        while (again.equalsIgnoreCase("y")) {
            System.out.print("Number of Stock A shares bought? ");
            double num_shares = Double.parseDouble(scanner.nextLine());

            System.out.print("Purchase price of Stock A? ");
            double a_price = Double.parseDouble(scanner.nextLine());

            System.out.print("Sale price of Stock A? ");
            double a_sell = Double.parseDouble(scanner.nextLine());

            System.out.print("Purchase price of Stock B? ");
            double b_price = Double.parseDouble(scanner.nextLine());

            double total_paid = calcStockCost(num_shares, a_price);
            double total_sell = calcStockCost(num_shares, a_sell);
            double total_gained = total_sell - total_paid;
            double shares_to_buy = sharesStock(total_sell, b_price);

            System.out.println();
            System.out.println("Total amount paid for Stock A: $" + String.format("%.2f", total_paid));
            System.out.println("Total amount received from selling Stock A: $" + String.format("%.2f", total_sell));

            if (total_gained >= 0) {
                System.out.println("You gained: $" + String.format("%.2f", total_gained));
            } else {
                System.out.println("You lost: $" + String.format("%.2f", -total_gained));
            }

            System.out.println("Number of Stock B shares you can buy: " + String.format("%.1f", shares_to_buy));

            System.out.println();
            System.out.print("Would you like to enter another set? (y/n): ");
            again = scanner.nextLine();
            System.out.println();
        }

        System.out.println("Program ended.");
        scanner.close();
    }

    public static double calcStockCost(double numShares, double stockPrice) {
        double cost = numShares * stockPrice;
        cost = Math.round(cost * 100.0) / 100.0;
        return cost;
    }

    public static double sharesStock(double totalAmount, double stockPrice) {
        double shares = totalAmount / stockPrice;
        shares = Math.round(shares * 10.0) / 10.0;
        return shares;
    }
}

Parallel arrays and an accumulated total

The Chapter 7 program stores six flavor names in one array and their case counts in another. The same index connects a name to its count. A second loop prints each pair, adds the count to a running total, and replaces the current best seller when it finds a larger value.

totalCases += casesSold[i];
if (casesSold[i] > highestSold) {
    highestSold = casesSold[i];
    topSeller = sodaFlavors[i];
}

/*
 * Programming Assignment 6
 * Soda Sales Program
 */

import java.util.Scanner;

class SodaSales {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        String[] sodaFlavors = new String[6];
        int[] casesSold = new int[6];

        for (int i = 0; i < 6; i++) {
            System.out.print("Enter soda flavor " + (i + 1) + ": ");
            sodaFlavors[i] = input.nextLine();

            System.out.print("Enter number of cases sold for " + sodaFlavors[i] + ": ");
            casesSold[i] = Integer.parseInt(input.nextLine());
            System.out.println();
        }

        int totalCases = 0;
        int highestSold = 0;
        String topSeller = "";

        System.out.println("Soda Sales Report");
        System.out.println("-----------------");

        for (int i = 0; i < 6; i++) {
            System.out.println(sodaFlavors[i] + ": " + casesSold[i] + " cases");
            totalCases += casesSold[i];
            if (casesSold[i] > highestSold) {
                highestSold = casesSold[i];
                topSeller = sodaFlavors[i];
            }
        }

        System.out.println();
        System.out.println("Total cases sold: " + totalCases);
        System.out.println("Top-selling flavor: " + topSeller);

        input.close();
    }
}
