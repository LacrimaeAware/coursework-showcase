A carpet contains a rectangle

The carpet package divides a small pricing program among three classes. A Rectangle stores dimensions and calculates area. A Carpet stores a rectangle together with a price per square yard. The report program creates carpet objects from keyboard input and prints their prices.

Class responsibilities
ClassStored information and behavior
RectangleLength, width and getArea().
CarpetA rectangle, a unit price and getTotalPrice().
CarpetReportInput loop, array of carpet objects and printed report.

This is composition: one object holds another object as a field. Carpet uses the rectangle's behavior instead of duplicating its area calculation.

public double getTotalPrice() {
    return rectangle.getArea() * pricePerSqYd;
}

Dimensions, unit price and object state

Using dimensions of \(3\) yards by \(4\) yards and a unit price of \(5\) dollars per square yard gives

\[\begin{aligned} A &= 3\times4 = 12\ \text{square yards},\\ C &= 12\times5 = 60\ \text{dollars}. \end{aligned}\]

The example execution prints Total Price: 60.0. The setters update the stored dimensions and price before the getter computes this value. The report keeps up to five carpet objects in an array, preserving each object's own dimensions and price.

The three source files share the carpet package. Compile them together with javac -encoding UTF-8 -d classes Rectangle.java Carpet.java CarpetReport.java, then run java -cp classes carpet.CarpetReport.

Rectangle.java

package carpet;

class Rectangle
{
    private double length;
    private double width;
    Rectangle(){
        length = 0;
        width = 0;
    }
    Rectangle (double len, double wid){
        length = len;
        width = wid;
    }
    public void setLength(double len)
    { length = len; }
    public void setWidth(double wid)
    { width = wid; }
    public double getLength()
    { return length; }
    public double getWidth()
    { return width; }
    public double getArea()
    { return length * width; }
}

Carpet.java

package carpet;

public class Carpet {

    // Vars
    private Rectangle rectangle;
    private double pricePerSqYd;

    // Default Constructor
    public Carpet() {
        rectangle = new Rectangle();
        pricePerSqYd = 0.0;
    }

    // Set
    public void setDimensions(double length, double width) {
        rectangle.setLength(length);
        rectangle.setWidth(width);
    }
    public void setPricePerYd(double pricePerSqYd) {
        this.pricePerSqYd = pricePerSqYd;
    }

    // Get
    public Rectangle get_Rectangle() {
        return rectangle;
    }
    public double get_PricePerSqYd() {
        return pricePerSqYd;
    }

    // Method
    public double getTotalPrice() {
        return rectangle.getArea() * pricePerSqYd;
    }
}

CarpetReport.java

package carpet;

/*
 * Programming Discussion 5
 * Carpet Data
 */

import java.util.Scanner;

public class CarpetReport {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Vars
        Carpet[] carpets = new Carpet[5];
        int count = 0;
        boolean term = false;
        String flirt = "✦";

        // Intro
        System.out.println(flirt.repeat(15));

        // Loop
        while (!term) {
            Carpet carpet = new Carpet();

            System.out.print("Enter length: ");
            double length = Double.parseDouble(scanner.nextLine());
            System.out.print("Enter width: ");
            double width = Double.parseDouble(scanner.nextLine());
            carpet.setDimensions(length, width);

            System.out.print("Enter price per square yard: ");
            double price = Double.parseDouble(scanner.nextLine());
            carpet.setPricePerYd(price);

            carpets[count] = carpet;
            count = count + 1;

            System.out.print('\n');
            System.out.print("Do you wish to continue? [Y/N]: ");
            String response = scanner.nextLine();
            System.out.print('\n');

            term = (count == 5 || response.toLowerCase().startsWith("n"));
        }

        // Display
        for (int i = 0; i < count; i++) {
            System.out.print('\n');
            System.out.print("Length: " + carpets[i].get_Rectangle().getLength());
            System.out.print('\n');
            System.out.print("Width: " + carpets[i].get_Rectangle().getWidth());
            System.out.print('\n');
            System.out.print("Price per square yard: " + carpets[i].get_PricePerSqYd());
            System.out.print('\n');
            System.out.print("Total Price: " + carpets[i].getTotalPrice());
            System.out.print('\n');
        }

        // Outro
        System.out.print("\nTerminating...\n");
        System.out.println(flirt.repeat(15));
    }
}
