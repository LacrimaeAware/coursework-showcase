Rows, columns and repeated calculations

Homework 1 begins with selecting observations from a data frame, a table whose columns can hold different kinds of variables. In R, cystfibr[c(5, 10, 15), ] selects three specified rows; the empty position after the comma retains every column. Logical conditions select observations by their values instead of their row numbers.

Homework 2 turns these individual selections into a calculation repeated across columns. The supplied ISwR::cystfibr teaching data contain \(25\) observations. The code selects numeric columns, removes missing values in each column, and calculates its mean and sample standard deviation. The latter measures spread about the mean using \(n-1\) in the denominator.

library(ISwR)
data(cystfibr)
numeric_data <- cystfibr[
  , sapply(cystfibr, is.numeric)
]
num_vars <- ncol(numeric_data)
means <- numeric(num_vars)
sds <- numeric(num_vars)

for (index in 1:num_vars) {
  values <- numeric_data[, index]
  values <- values[!is.na(values)]
  n <- length(values)
  mean_value <- sum(values) / n
  sd_value <- sqrt(
    sum((values - mean_value)^2) / (n - 1)
  )
  means[index] <- mean_value
  sds[index] <- sd_value
}
cbind(mean = means, sd = sds)

sapply() tests each column with is.numeric(). Inside the loop, is.na() marks missing entries and ! reverses that test, retaining observed values. Each column has its own count \(n\). The loop stores its results, then cbind() places the means and standard deviations side by side.

Numeric storage alone does not establish what a variable means. For example, a numeric category code should not automatically be interpreted like a measurement of height. The summary must retain each column's definition and units.

Variation within and between groups

The second exercise compares three holding-time vectors. Their sample means are \(5.4\), \(2.8\) and \(10.4\). A constructed comparison uses different observations whose three means are all \(5\). This separates a difference in group centers from the spread of observations inside each group.

Here, “between” is the average squared distance of the three means from the grand mean, the mean across all \(15\) observations; “within” is the average of the three sample variances. Their ratio is \(0.8574713\) for the assignment vectors and \(0\) for the constructed comparison. This exploratory ratio is not yet the ANOVA \(F\) statistic: ANOVA scales the sums of squares by their degrees of freedom, as the next chapter shows.
