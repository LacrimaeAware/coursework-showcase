Prompted masks with SAM

Assignment 7 applies Segment Anything Model (SAM) to five images. A segmentation mask marks the pixels assigned to a target object. The comparison supplies either a foreground point or a bounding box, then examines how the prompt changes the selected region.

The report describes clean separation for a strongly bounded isolated figure. More ambiguous scenes produce different selections: a point sometimes prioritizes a shirt, while a box can include more of the intended subject. In another example, the box-prompt result selects hair around the intended facial region.

The code requests multiple mask candidates and chooses the candidate with the highest model score. That score ranks the model's candidates; the visual comparison still determines whether the chosen region matches the intended target.

Labeled boxes with RetinaNet

Assignment 8 uses Torchvision's pretrained RetinaNet detector with a ResNet-50 feature backbone. The model returns bounding boxes, class labels and confidence scores. The script retains detections with score at least \(0.50\), then draws their boxes and labels over the image.

The detector places one person box around the human figure. In crowded scenes, additional boxes appear around background people. A pile of snakes receives a bench label, providing a concrete example of a visually unfamiliar object being assigned to one of the detector's available categories.
