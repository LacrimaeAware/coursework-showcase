Seasonal airline-passenger forecasts

Assignment 9 predicts later observations from earlier values in a time series. The airline task uses monthly passenger counts from \(1949\) to \(1960\). Training, validation and test periods follow chronological order so model selection uses observations preceding the test period.

The selected Keras long short-term memory network (LSTM) receives the preceding \(12\) months and predicts the next month. Its recurrent state carries information through the input sequence. A seasonal baseline predicts from the corresponding month in the previous year.

The reported one-step test mean absolute error (MAE) is \(21.19\) thousand passengers, compared with \(35.92\) for the seasonal baseline. MAE averages the absolute prediction errors in the target's units. Recursive forecasting feeds predictions back into subsequent inputs; its MAE rises to \(29.83\) thousand passengers.

Seven-day Bitcoin returns

The second task forecasts the \(7\)-day log return of BTC-USD using price-history and market features. The original final run compares an LSTM, a temporal convolutional network (TCN), Extra Trees and simple return baselines on \(459\) test targets.

The zero-return baseline has the smallest error in this comparison. The TCN is the strongest learned model by return MAE. Predicting a future price near the current price can produce a plausible-looking curve, so the return target and baseline comparison help assess the forecast beyond its appearance.

The two datasets give different outcomes: the airline series has a visible seasonal pattern that the LSTM follows, while the Bitcoin comparison favors persistence. Chronological splits, target definition and a simple reference model make that difference interpretable.
