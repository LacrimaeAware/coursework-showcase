Searching for a separating line

The first assignment classifies two clouds of points in a plane using NumPy and Matplotlib. Each class contains \(100\) synthetic Gaussian samples. A linear score \(z=\mathbf{k}^{\mathsf T}\mathbf{x}+b\) assigns the class according to which side of the boundary a point falls on.

The search fixes the normal vector's length and varies its direction through \(\mathbf{k}=(\cos\theta,\sin\theta)\). It evaluates \(120\) angles and \(80\) offsets, measuring the fraction of incorrectly classified points at each pair.

The selected boundary has training error \(0.01\), or \(2\) errors among the \(200\) points. This small problem makes exhaustive search visible: each location on the loss surface corresponds to a particular line. As the number of parameters grows, the combinations multiply.

Learning the boundary with gradients

Assignment 2 replaces the hard class decision during optimization with a sigmoid probability, \(\hat y=\sigma(z)=1/(1+e^{-z})\). Binary cross-entropy penalizes confident predictions of the wrong class. Gradient descent changes each parameter in the direction that decreases this loss.

After \(200\) updates with learning rate \(0.5\), the recorded training accuracy is \(0.970\), with cross-entropy about \(0.05449\). The boundary changes continuously because the sigmoid loss supplies gradients even when a small movement leaves the class predictions unchanged.

The assignment also represents the pixels of a letter as coordinate points and applies translation, rotation and scaling matrices. Both tasks connect an algebraic representation to a visible geometric change.
