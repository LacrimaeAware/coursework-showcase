Seven-day Bitcoin log returns

This mini-project tests whether models can predict Bitcoin price changes more accurately than assuming the price stays where it is. Daily BTC-USD prices and market features are used to predict the change over the next \(7\) days.

The target is a log return, \(r_t=\log(C_{t+7}/C_t)\), where \(C_t\) is the closing price on day \(t\). A prediction of \(r_t=0\) means the future closing price equals the current one. This persistence forecast is a useful reference because a curve can follow Bitcoin's broad price level while adding little information about its next change.

Price history and chronological evaluation

The inputs include \(136\) features describing past returns, volatility, momentum, calendar cycles and other markets. Rolling summaries use observations available by the prediction day. Training, validation and test periods occur in chronological order; scaling is fitted before the validation period.

The selected long short-term memory network (LSTM) carries a learned state through the preceding \(60\) days of inputs. A temporal convolutional network (TCN) instead applies learned filters across a sequence. Extra Trees uses randomized decision trees that split observations by feature values, then averages their predictions.

The final test comparison contains \(459\) targets. Model settings are selected on validation data, then evaluated on the later test period from January 2025 through April 2026.

Mean absolute error (MAE) averages the absolute differences between predicted and actual log returns. The zero-return baseline has the smallest error. The TCN is the strongest learned model in this comparison, while the selected LSTM also has directional accuracy of \(47.71\%\): fewer than half its predicted return signs match the actual signs.

For this target and test period, the learned models do not improve on persistence by return MAE. The comparison distinguishes following a price level from predicting a price change: a plausible-looking forecast curve can conceal a larger error than the simplest reference model.
